# King Music

> Ветка `port/fabric-1.21.1`: порт только Core 0.5.16, Lyrics 0.1.5 и Visualizer 0.1.1
> из актуальных исходников GitHub (`53e8de7`). Сборка: **JDK 21**, `gradlew.bat build`.
> Подробности и проверенные возможности — [PORT_1.21.1.md](PORT_1.21.1.md).
> Описание 26.2 ниже относится к основной ветке; Together в сборку этой ветки не входит.

**King Music** — музыкальный плеер для Minecraft 26.2 от **King220l**. Он умеет слушать
Яндекс Музыку прямо в игре и воспроизводить музыку из папки на компьютере.

## Быстрый старт для игрока

### Что нужно установить

1. Установи Minecraft 26.2, Fabric Loader и Fabric API.
2. Положи `King-Music-0.5.16-Fabric-26.2.jar` в папку `mods` своего профиля.
3. Удали старую версию King Music из `mods`, если она там осталась.
4. Запусти игру и нажми **F8**.

Клавишу F8 можно поменять в **Настройки Minecraft → Управление → Назначение клавиш → King Music**.

### Как войти в Яндекс Музыку

Открой в плеере страницу аккаунта. Введи или вставь токен Яндекс Музыки в скрытое поле и
нажми **Войти**. Кнопка рядом временно показывает или снова скрывает введённый токен.

Вход по коду Яндекса оставлен как дополнительный вариант. Используй его только в официальной
сборке King220l. Токен не обходит подписку, региональные ограничения и правила Яндекса.

Один из внешних способов получить токен — [ym-token.marshal.dev](https://ym-token.marshal.dev/).
Это сторонний сервис, он не принадлежит King220l и не входит в King Music. Всегда проверяй адрес
сайта перед входом. Не отправляй полученный токен другим людям и не публикуй его.

### Язык интерфейса

По умолчанию используется английский. Русский выбирается в **Settings → Player → Language**.
Дополнительные языки можно добавить без пересборки мода: положи UTF-8 файл `код_языка.lang` или
`код_языка.json` в `config/yamusic/lang`. После перезапуска язык автоматически появится в списке.

Пример `.lang`:

```properties
language.name=Українська
Главная=Головна
Поиск=Пошук
Библиотека=Бібліотека
```

Полный стартовый пример находится в `language-packs/uk_ua.lang.example`. Ключ слева — исходная
русская фраза интерфейса, значение справа — перевод. Строки, которых нет в пакете, показываются
по-английски только для встроенного `en_us`; в стороннем пакете они остаются исходными, чтобы
незавершённый перевод было легко заметить.

### Основные возможности

- **F8** открывает полный плеер.
- **Ctrl+P** включает паузу или продолжает воспроизведение.
- **Ctrl+N** переключает на следующий трек.
- Остальные клавиши можно назначить в **King Music → Настройки → Клавиши**.
- Поддерживаются клавиатура, кнопки мыши и сочетания с Ctrl, Alt и Shift.
- В меню паузы работает мини-плеер.
- Полосу времени можно нажимать и перетаскивать для перемотки.
- Громкость, качество музыки, масштаб интерфейса и HUD настраиваются внутри мода.
- Интерфейс можно уменьшить до 50%, чтобы в списках помещалось больше музыки.

### Как воспроизводятся треки

- Трек из поиска запускается сразу. После него кнопка **Следующий** или окончание песни включает
  «Мою волну» по выбранному треку.
- Плейлисты, «Любимое» и «Моя папка» играют последовательно по своим спискам.
- В разделе **Недавние** хранятся до 40 уже звучавших треков. Их можно запустить повторно.
- «Моя волна» помнит недавние рекомендации и старается не повторять их после перезапуска игры.

### Музыка с компьютера

Открой **Моя папка → Выбрать папку**. Поддерживаются MP3, WAV, AIFF и AU. Мод просматривает
выбранную папку и вложенные папки. Локальная музыка работает без входа в Яндекс.

## Дополнения

Все дополнения необязательны. Основной King Music работает без них.

### King Music Together

Файл `King-Music-Together-0.2.1-Fabric-26.2.jar` добавляет совместное прослушивание.

- Ведущий выбирает музыку, управляет паузой и перемоткой.
- Каждый участник воспроизводит трек через собственный аккаунт Яндекса.
- Токены, локальные файлы и прямые ссылки на аудио другим игрокам не передаются.
- Для надёжной комнаты на Fabric-сервер устанавливается
  `King-Music-Together-Server-0.1.1-Fabric-26.2.jar`.
- Бета-режим связи без серверного дополнения можно включить в настройках Together.
- Если ведущий пропал, роль сохраняется за ним две минуты, а затем передаётся участнику.

### King Music Lyrics

Файл `King-Music-Lyrics-0.1.5-Fabric-26.2.jar` добавляет синхронный текст песен и редактор LRC.

- Текущая строка подсвечивается и прокручивается по времени.
- Нажатие на строку перематывает трек к её началу.
- Для локальной песни положи рядом одноимённый `.lrc` или `.txt`.
- В редакторе можно ставить и перетаскивать метки, замедлять воспроизведение и точно менять время.
- HUD текста переносится по экрану. Его размер, прозрачность, оформление и число строк настраиваются.

### King Music Visualizer

Файл `King-Music-Visualizer-0.1.1-Fabric-26.2.jar` добавляет пять визуализаторов — спектр,
волну, кольцо, пульс и стерео. Визуализатор можно полностью отключить в настройках.

## Как проверить официальную сборку

При запуске King Music загружает с этого репозитория небольшой подписанный список официальных
файлов. Мод проверяет цифровую подпись Ed25519 и SHA-256 основного JAR и установленных дополнений.

- **Официальная сборка** совпадает с файлом, опубликованным King220l.
- **Изменённая сборка** продолжит воспроизводить локальную музыку, но вход в Яндекс будет
  заблокирован, чтобы не передавать токен неизвестному коду.
- Последняя успешно проверенная подпись сохраняется локально. Поэтому кратковременная
  недоступность GitHub не отключает уже проверенную версию.
- Открытый ключ встроен в мод. Закрытый ключ выпуска хранится отдельно и не публикуется.

Ни одна встроенная проверка не может сделать открытый JAR абсолютно неизменяемым. Человек может
создать форк и удалить проверку. Такой файл не совпадёт с официальным хешем и не должен называться
официальным King Music. Подробности находятся в [BRAND_POLICY.md](BRAND_POLICY.md).

## Безопасность аккаунта

- Токен проверяется через Яндекс до сохранения.
- Поле токена скрыто по умолчанию и очищается после начала входа.
- В Windows сеанс шифруется через DPAPI для текущего пользователя
- Токен отправляется только на HTTPS-адреса Яндекса и не передаётся в комнаты Together.
- Выход из аккаунта удаляет сохранённый сеанс.

DPAPI защищает файл от другого пользователя Windows и от простого копирования. Программа,
запущенная с правами того же пользователя Windows, потенциально может получить доступ к данным.

## Для разработчиков

### Сборка

Нужны JDK 25, Python 3 и установленный профиль Minecraft 26.2 с Fabric API. Запусти:

```powershell
python build.py
```

Готовые JAR появятся в `build`. Скрипт также создаёт `official/manifest.txt` и подписывает его,
если закрытый ключ выпуска присутствует в `%USERPROFILE%/.kingmusic/release-signing.pk8`.

### Структура проекта

- `src` — основной клиентский мод.
- `addon` — клиентское дополнение Together.
- `together-server` — серверная часть Together для Fabric.
- `lyrics` — тексты песен и редактор LRC.
- `visualizer` — визуализация звука.
- `official` — подписанный список официальных файлов.
- `tools` — инструмент подписи релизов.

### Лицензия и модификации

Исходный код выпущен по [MIT License](LICENSE). Разрешены изучение, изменение и создание форков
при сохранении уведомления об авторских правах. Изменённые сборки необходимо ясно обозначать как
неофициальные и нельзя выдавать за подписанные релизы King220l.


## Используемые проекты

Работа с Яндекс Музыкой основана на интерфейсе сервиса, описанном сообществом
[yandex-music-api](https://github.com/MarshalX/yandex-music-api). MP3-декодирование использует
JLayer. Уведомления о сторонних компонентах находятся в `resources/THIRD-PARTY.txt`.
