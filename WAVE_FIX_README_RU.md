# KING Music — исправление повторов «Моей волны»

Этот исходный код содержит изменения для ручного переключения «Моей волны». В ручном пропуске обновляется история, фильтрация исключает недавно проигранные композиции, а при пустой выдаче выполняются до двух дополнительных запросов.

**Статус: исходный патч, не проверен сборкой/запуском Minecraft.**

Собирайте на Windows с JDK 25 и установленным Modrinth-профилем WSH_1_0_0 (Minecraft 26.2, Fabric API) с помощью `python build.py`.

Это НЕ официальный релиз. Установленные проверки цифровой подписи могут отклонить тестовую сборку. Не публикуйте JAR до проверки на реальной установке и официального подписания вашим ключом. Закрытый ключ не отправляйте в чат.
